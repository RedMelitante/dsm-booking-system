This left side is the client's own website. The panel on the right is the booking app running in an iframe with ?embed=true: no app header, footer or grey page background, a compact stepper, and the summary moved into a sticky bottom bar so it works at any width.

Embed snippet (from Dashboard › Booking page) Copy
<iframe src="https://[domain]/lumen-skin-studio?embed=true" title="Book an appointment" loading="lazy" style="width:100%;min-height:720px;border:0"></iframe> <script src="https://[domain]/embed.js" async></script>
embed.js listens for height messages from the iframe and resizes it, so there is no inner scrollbar on the live site. The widget uses the business's accent colour and logo from the dashboard, nothing from the host page's CSS. Optional params: &service=, &staff=, &hide_staff=1 to deep-link straight into a step.
